# Isotonic Regression with Python and scikit-learn

Python scripts fitting isotonic (monotonic) regression with scikit-learn and comparing it with linear regression, on Mariana Trench data. Reusable data-analysis example.

## Scripts

- `isotonic_regression_bathy.py`
- `isotonic_regression_subplots.py`

## Data

- `Tab-Morph.csv`

## Requirements

Python 3 with `matplotlib`, `numpy`, `pandas`, `seaborn`, `scikit-learn`.

```
pip install matplotlib numpy pandas seaborn scikit-learn
```
